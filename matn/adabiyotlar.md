## Standartlar va rasmiy hujjatlar

1. MITRE Corporation. Common Weakness Enumeration (CWE). —
   https://cwe.mitre.org/

2. MITRE Corporation. CWE Top 25 Most Dangerous Software Weaknesses. —
   https://cwe.mitre.org/top25/

3. OWASP Foundation. OWASP Top 10 Web Application Security Risks. —
   https://owasp.org/www-project-top-ten/

4. OWASP Foundation. Source Code Analysis Tools. —
   https://owasp.org/www-community/Source_Code_Analysis_Tools

5. NIST. Special Publication 800-218: Secure Software Development
   Framework (SSDF). — https://csrc.nist.gov/publications/detail/sp/800-218/final

6. NIST. SAMATE — Software Assurance Metrics And Tool Evaluation. —
   https://www.nist.gov/itl/ssd/software-quality-group/samate

7. NIST. National Vulnerability Database (NVD). — https://nvd.nist.gov/

8. FIRST. Common Vulnerability Scoring System (CVSS) v4.0. —
   https://www.first.org/cvss/
